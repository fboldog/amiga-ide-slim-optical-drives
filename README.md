# Amiga IDE/ATA slim optical drives

List of working and tested slim IDE/ATA optical drives for Amiga.

No special adapter or software required, except the standard IDE 44 -> Slimline adapter.

To connect Amiga IDE port to Slimline CD/DVD you will need adapter like this:
- PA-CD2 \(for example: [Delock 61533](https://www.delock.com/produkt/61533/merkmale.html)\)
